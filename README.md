# 🏰 Software Empire Solutions

Plataforma web profesional para **Software Empire Solutions**, orientada a la presentación de servicios de desarrollo de software, landing pages y soluciones tecnológicas a la medida.

---

## 🛠️ Tech Stack

* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Lenguaje:** TypeScript
* **Estilos:** Tailwind CSS
* **Fuentes:** `next/font` con la familia Geist

---
